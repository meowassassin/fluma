# 영상 디자이너 (그리지 않고 배치한다)

> **파이프라인 적용(2026-11-11)**: `produce.py` 가 렌더 전 `skill_pass.py designer`(배치 · 자막 · 글꼴 · 재료 크기 · Astryx 앱 화면)와 렌더 뒤 `skill_pass.py review`(장면 정지 화면을 직접 열어 겹침 · 잘림 · 작은 주인공을 고침 → 다시 렌더)를 돌린다.

이 자리에서 하는 일은 재료(자료 화면 · 퍼온 클립 · 사진 · 짤 · 도표 · 목업 · 글자)를 9:16 화면에 앉히는 것이다. 설명형 영상의 장면 화면은 실제 화면 · UI 목업 · 자료로 구성한다. 단색 바탕 + 가운데 물건 + 라벨은 '정보 나열'이다(2026-11-11).

## 1. 레퍼런스에서 재고 시작한다 (짐작 금지)
레퍼런스가 있으면 `data/public/trends/xray/<id>/style/style.json` · `style.md`(ref_style.py 결과)의 숫자를 그대로 쓴다: `layout.letterbox_ratio` · `band_top/bottom` · `background`, `captions.items[].y · h · bg · fg`, `rhythm.avg_shot_sec · first_shot_sec · camera_static_ratio`.
`python3 engine/story/direct.py data/storyboards/<id>.json --write` 가 이 값을 direction 에 옮긴다. 옮긴 뒤 아래 표와 다르면 **레퍼런스가 이긴다**.

레퍼런스가 없을 때의 기본값 — 2026-11-11 레퍼런스 쇼츠 28편 실측(중앙값):
| 항목 | 실측 | 기본으로 |
|---|---|---|
| 레이아웃 | 22/28 편이 단색 바탕 + 가운데 띠(퍼온 클립 · 화면 녹화 쇼츠) | 클립 · 녹화는 `card`(띠), 사진 · 짤이 주인공이면 `full` |
| 자막 글자 높이 | 화면 높이의 약 4%(1920 기준 75~80px 한 줄) | 자막 한 줄 70~84px, 두 줄까지 |
| 자막 모양 | 흰 상자 + 검은 글씨, 또는 검은 바탕 + 흰 글씨 두 가지뿐 | `subs.box: true` + 단색 둘 중 하나. 그라데이션 · 외곽선 3중 · 그림자 남발 금지 |
| 자막 위치 | 위 띠 · 아래 띠에 몰림(가운데 띠는 내용 자리) | 띠 레이아웃이면 아래 띠, 가득이면 y 0.62~0.72 |
| 컷 길이 | 평균 3.2초(사분위 1.8~6.7) · 첫 컷 3초 | 말 주도는 2~4초, 짤 · 음악 주도는 1~1.5초 |
| 카메라 | 69% 가 고정 | 밀기 · 흔들기는 근거 있을 때만(`cam_push` 기본 1.0) |

## 2. 정할 것 (콘티 `direction` — 칸 설명은 engine/craft/design.py 맨 위)
1. **레이아웃** `layout` — full | card. 한 영상 안에서 섞지 않는다(레퍼런스가 섞을 때만).
2. **글자 위계 세 단계만**: 고정 제목(위 띠, 가장 큼) · 자막(아래, 중간) · 주석(`overlay` 라벨, 가장 작음). 네 번째 크기를 만들지 않는다.
3. **색** `direction.art.palette{bg, ink, accent}` — 강조색 하나. accent 는 강조 낱말(`subs.hot`) · 주석 상자 · 차트 최대값에만. 기본 보라 금지(D14).
4. **글꼴** — 제목 하나 + 본문 하나. 정보 · 기술 Pretendard, 강한 제목 Black Han Sans, 신뢰 · 지면 Gowun Batang, 손글씨 Nanum Pen. 영상마다 고르되 한 영상 두 가지까지.
5. **안전 영역** — 위 8%(상태 표시줄) · 아래 18%(쇼츠 제목 · 버튼) · 오른쪽 12%(좋아요 · 댓글 버튼)에 읽어야 할 글자를 두지 않는다.
6. **실제 화면 앉히기** — 캡처는 짚을 곳만 남기고 자른다(`crop`). 1080 폭에서 본문 글자가 28px 보다 작으면 `zoom` 으로 들어간다. 테두리 · 그림자는 `frame` 으로, 근거 있을 때만.
7. **글자 타이밍** — 화면 글자는 그 말이 나올 때(`cue`) 나와서 다음 말 전에 사라진다. 한 화면에 읽을 글자 12자 이내(제목 제외).

## 3. 보고 고친다 (매번)
`produce.py` 뒤 정지 화면(또는 `knob.py preview <id> --scene <n>`)을 Read 로 보고 장면마다 확인:
1. 3초 안에 시선이 갈 곳이 하나인가 — 둘 이상이면 하나를 줄인다.
2. 자막 · 제목이 안전 영역 밖에 있고, 바탕 위에서 읽히는가(대비).
3. 띠 안 내용이 띠를 70% 이상 채우는가(D12 작은 주인공).
4. 글자 크기가 세 단계로만 보이는가.
5. 앞 장면과 구도가 같지 않은가(D13).
고칠 때는 값으로: `knob.py set <id> s3.<요소>.adjust.scale=*1.2 direction.subs.y=0.7` — 좌표 · SVG 를 손으로 고치지 않는다.
