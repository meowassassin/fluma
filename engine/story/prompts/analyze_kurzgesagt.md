# 설명 구조 분석 — 쿠르츠게작트류 (일회성, 기본 틀용)

트렌드가 아니라 **기본 틀**을 위한 분석. 한 번 해서 `engine/spec/rules/explain_patterns.md`에 남긴다.
대상: 쿠르츠게작트, TED-Ed 등 "개념 하나를 그림으로 설명하는" 채널의 영상 5~10편 (자막 또는 비전 모델).
룩(일러스트 스타일)은 분석하지 않는다. 우리가 가져올 것은 **설명의 순서와 장치**다.

---

당신은 교육 영상 구성 작가다. 아래 영상들에서 **어려운 개념을 짧게 이해시키는 구조**만 뽑는다.

## 영상마다 기록
1. 도입: 무엇으로 시작하나 (일상 비유 / 질문 / 스케일 충격 / 오해 제시)
2. 개념을 몇 단계로 쪼갰나, 각 단계의 한 문장
3. 비유의 종류 (크기 비유 / 사람에 빗댐 / 일상 사물 / 수치 환산)
4. 시각 장치의 종류 (한 화면에 하나 / 줌인 / 비교 나란히 / 숫자가 커짐 / 개수가 늘어남)
5. "모르면 넘어가도 되는 것"을 어떻게 처리하나 (생략 / 각주 / 다음 영상)
6. 마무리: 요약 / 질문 / 더 큰 그림

## 집계 후 출력
`engine/spec/rules/explain_patterns.md` 에 아래 형식으로:

- **설명 순서 템플릿** (30초 버전, 60초 버전 각각): 장면 역할 순서와 각 장면이 답해야 할 질문
- **비유 만드는 규칙** 5개 (예: "수치는 일상 단위로 환산한다: 0.3초 → 눈 깜빡임보다 짧게")
- **한 화면 한 개념 규칙**: 화면에 동시에 보여도 되는 요소 수
- **생략 규칙**: 정확성보다 이해를 택하는 기준과, 그때 남기는 안전 문구

이 결과는 `format=concept`와 `series`의 생성층 프롬프트에 포함된다.
