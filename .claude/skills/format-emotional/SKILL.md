# 감성 (emotional)

## 지킬 조건
- 길이 20초(최대 30). 자막은 14자 이하(L13), 한 문장, 마침표 없이. 숫자 장면은 1개 이하.
- 나레이션은 없어도 된다(L04 하한 없음). `music_cue` 로 흐름을 준다.
- 스틸만 있어도 움직이게: 장면마다 `visual.motion`(kenburns_in/out, pan_left/right)을 다르게.
- 시간 · 장소 · 손을 보여 준다: "새벽 4시", "선별장", "상차".
- 현장 사진 · 영상이 없으면 무료 스톡 영상(재료 `stock`, 영어 검색어 — 예: `"dawn market hands"`). 장면마다 다른 클립, 사람 얼굴이 크게 나오면 사용자에게 확인. 출처는 설명란에 자동. 키가 없으면(검사 L38) 설정 → API 키의 Pexels · Pixabay(무료)를 부탁.

## 흔한 구조(= 뻔함 지도 후보, 정답 아님)
- 스틸 훅 → 분위기 장면 3~5 → CTA, 잔잔한 피아노가 올라가는 음악.
- 다르게 가는 예: 소리 하나(칼질 · 경매 호가)로 끌고 가기, 한 사람의 하루를 거꾸로, 끝까지 얼굴 없이 손만.
- 참고: `data/storyboards/2026-10-26-client-cheongwoon-emotional-03.json`

## 구조는 정해 두지 않는다
이 형식에 '정답 순서'는 없다. 아래 "흔한 구조"는 레퍼런스에서 자주 보이는 것일 뿐이고, 그대로 쓰면 다른 영상과 똑같아진다.
1. 레퍼런스 3~5편 X-ray 를 보고 plan 스킬 0턴의 **뻔함 지도**(`concepts.py` 의 `cliches`)를 먼저 적는다 — 흔한 구조는 거기 후보로.
2. 안마다 그중 하나를 **일부러 깨고**(`breaks`), 장면 흐름(`structure`)은 그 안의 한 방에서 나온다.
3. 제목도 지도의 제목 패턴을 피한다. 고르는 것은 사용자.
