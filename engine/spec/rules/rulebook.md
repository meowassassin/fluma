# 규칙집 (rulebook)

결정층과 검사층이 읽는 기준. 영상을 만들며 배운 것을 여기에 쌓는다.
**규칙 하나 = 한 줄 + 근거 + 날짜.** 근거 없는 규칙은 넣지 않는다.

## 0. 불변 (트렌드가 바꿀 수 없음)
- 한 편에 포인트 하나. 두 개면 두 편으로 쪼갠다.
- 첫 장면(hook)은 3초 이내, 질문이거나 숫자다.
- 자막은 한 화면 2줄, 28자 이내. 음성은 초당 4~7자 (공백 제외, 자연스러운 한국어 5~6자/초).
- 마지막 장면은 첫 장면과 이어진다 (루프). outro 자막은 hook의 질문에 답하거나 되묻는다.
- 숫자는 한 편에 4개까지. 그 이상이면 countdown 형식으로 바꾼다.
- 사실·수치에는 sources를 남긴다. 출처 없는 수치는 생성층이 만들지 않는다.
- 고객 데이터·내부 정보는 입력하지 않는다. 공개 가능한 내용만.

## 1. 결정층 규칙 (형식 선택)
우선순위 순서로 적용. 첫 번째로 맞는 것을 고른다. 아무것도 안 맞으면 `trend_overrides.format_weights`로 가중 선택.

| 조건 (주제 문장에서) | 형식 | 장면 구성 |
|---|---|---|
| "vs", "비교", "차이", 항목이 2~3개 | compare | hook, item×N, verdict, outro |
| "TOP", "순위", "N가지", "N개" (N≥3) | countdown | hook, item×N (역순), verdict, outro |
| "사실은", "오해", "착각", "진짜", "아닌" | mythbust | hook, contrast, reveal, verdict, outro |
| "방법", "하는 법", "해결", "줄이는", "고치는" | fix | hook, setup, step×2~3, verdict, outro |
| "원리", "어떻게 동작", "구조", "왜" | concept | hook, setup, reveal×2, verdict, outro |
| 주제가 넓고 60초로 부족 | series (3부작) | 각 편은 concept 구조, series.part 표기 |
| 시안이 "광고" 지정 | ad | hook, benefit×2~4, proof, cta — 15초, 배지 필수 |
| 시안이 "감성" 지정 | emotional | hook, mood×3~5, cta — 20초, 자막 14자 이하, 숫자 최소 |
| 시안이 "당일 시세" 지정 | daily | hook, price×1~3, mood, cta — 15초, 가격 하나 크게 + 반응 |

시안(브리프)의 형식 지정은 주제 문장 규칙보다 우선한다.

## 2. 길이 규칙
- 길이는 형식으로 정한다 (2026-10-28 채널 구분 폐지): 기본 30초, 광고·시세 15초, 감성 20초, 시리즈 30초, 항목이 많으면 +4초씩(최대 60). 사용자가 목표 길이를 주면 그 값.
- 음성이 장면 길이를 정한다: assemble_audio.py 가 실측 말 길이로 sec 를 다시 쓴다 (위 값은 목표치).
- 장면 수 = round(duration / 6), 최소 3 최대 8. hook 3초, outro 3초는 고정.

## 3. 생성층 규칙 (칸 채우기 프롬프트에 그대로 들어감)
- 모든 본문 장면에 고유명사나 숫자 하나 이상. 평가어("좋다")는 값("4/5", "월 1만 자")과 함께.
- 자막은 명사형·구어체 짧게. "~입니다" 금지, "~예요/~해요" 또는 명사 종결.
- 한 장면에 새 정보 하나. 앞 장면 반복 금지.
- 영어 약어는 첫 등장에 한글 설명 없이 그대로 (타깃이 실무자).
- 금칙어: "충격", "경악", "미쳤다", "역대급", "꼭 보세요".
- 숫자는 아라비아 숫자, 단위 붙임 (37%, 3개, 0원).

## 4. 검사층 규칙 (코드로 검사, engine/checks/lint.py)
- L01 스키마 통과
- L02 scenes[].sec 합계 == duration_sec (±1)
- L03 caption ≤ 28자, 줄바꿈 ≤ 1
- L04 narration 글자수(공백 제외) / sec 가 4~7
- L05 hook.sec ≤ 3
- L06 금칙어 없음
- L07 숫자(visual.kind=number) ≤ 4
- L08 outro.caption 또는 narration에 hook의 핵심어 1개 이상 포함 (루프)
- L09 같은 caption 반복 없음
- L10 최근 30편 title과 유사도 < 0.8 (중복 업로드 방지)
- L11 hook·outro 외 모든 장면에 숫자 또는 고유명사(또는 screenshot/code/chart 화면) 하나 이상 — 빈약한 장면 금지
- L39 재료 칸: 종류별 필수 칸(doc_quote pdf · find, diagram kind · items, model3d shape|commands|src …), overlay 의 target 은 같은 장면의 앞선 그림 · 화면 재료, drawing 의 model id 는 앞선 model3d, 가상 화면 ui_mock 은 mock: true, 재료 id 에 '.' 금지

## 4-1. 조사층 규칙 (engine/research/research.py)
- 생성 전에 반드시 조사. 출처 URL 없는 사실은 버린다. 출처 있는 사실이 5개 미만이면 그 주제는 만들지 않는다.
- 비교 주제는 항목마다 같은 기준의 값 2개 이상.
- 가격·한도는 확인 날짜를 남기고 caveats에 "변동 가능".
- 생성층은 조사 목록 밖의 수치·이름을 쓰지 않는다.

- L12 compare/fix/ad/emotional/daily 의 본문 장면 절반 이상이 실제 화면(screenshot/still/footage/price_tag/audio_demo)
- L13 emotional 의 mood 자막은 14자 이하
- L14 실측 음성(data/audio/<id>.timing.json)이 장면 sec 의 1.15배를 넘으면 실패. 글자 수 추정(L04)은 실제 TTS 길이를 못 잡는다 (2026-10-27 회전초밥 광고: L04 통과, CTA 4.30s/3s 잘림)

## 4-2. 분석에서 나온 규칙 (2026-10-26, 실제 쇼츠 10편 장면 단위 분석)
- **현장이 증거다.** 툴은 실제 UI 녹화, 매장은 손님 있는 영상, 농산물은 상품+손글씨 가격표. 그래픽은 그 위 자막 한 줄.
- **숫자는 하나, 크게.** 시세표 10줄(572회) vs 손글씨 가격 하나(48만회).
- **감정이 숫자를 운반한다.** 시세·광고 모두 반응 문장("이러다 다죽어!", "아직도 유료로?")이 데이터보다 먼저.
- **제품이 스스로 증명하게.** TTS 영상의 나레이션은 그 TTS로. 음식은 먹는 장면으로.
- **광고는 광고 배지를 달되 현장을 보여준다.** 카피만 있는 광고(114회)는 안 본다.
- **정돈된 데이터 패널은 보조.** Dashboard 류는 데이터·원리 주제에만. 툴·현장·광고·감성은 Overlay.
- 길이: 광고·시세 15~20초, 감성 20~30초, 툴 리뷰 19~50초.

## 5. 배운 것 (날짜순, 승급층·사람 수정에서 추출)
- (여기에 추가) 예: 2026-11-05 — "장점·단점을 한 칸에 쓰면 28자를 넘김 → compare의 item은 items 배열로 분리" — 근거: 3편 연속 L03 실패

## 6. 트렌드 반영 규칙
- 트렌드 층은 1절(불변)을 건드리지 못한다.
- 바꿀 수 있는 것: format_weights, hook_style_weights, trend_overrides의 range 내 값, 주제 후보 목록.
- 새 형식·새 시그니처 장치·룩 변경은 `engine/spec/rules/trends/proposals.md`에 제안만 남기고 사람이 승인한다.
