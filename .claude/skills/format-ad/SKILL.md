# 광고 (ad)

- 길이 15초. 장면: hook(3) → benefit×2~4 → proof → cta(3). 훅 화면은 still.
- `badge` 필수 (예: "창업 15초", "광고"). 하단 면책: 마지막 장면 소자막 + `caption`(설명란)에 "매장·상권에 따라 다를 수 있습니다".
- **수치는 클라이언트 제공값만** (`briefs/` 확인). 없는 수치(순수익율·객단가 등)는 장면에 넣지 않는다.
- 본문 절반 이상이 실제 장면(still/footage). 카피만 있는 광고는 안 본다 (분석: 114회).
- 큰 값 하나: "회전율 3배", "₩2,200 균일가" 같은 6자 안팎.
- 화면은 compose 스킬로 영상마다 짠다(색은 direction). 굵은 노랑 강조가 어울린다.
- 참고: 이 형식으로 만든 콘티 `storyboards/<id>.json`
