# 순위 모음 (ranking)

레퍼런스 X-ray(VpX4x1_RZoo · 고양이 동물 모먼트 TOP5): 20초 · 7컷 · 평균 2.8초 · 첫 컷 4초 · 음악 95% · 말 4%(효과음 · 반응 소리만) · 화면 글자 17번 · 반응 자막은 화면 높이 63~69%(영상 위 아래쪽).

## 순서
1. **후보 찾기** — `python3 engine/capture/clip.py search "<주제 영어로도>" --shorts --max-sec 60 --n 40`(조회 1만 미만 · AI 생성 영상은 자동 제외). 목록을 사용자에게 보이고 쓸 것을 고른다. 한국어 · 영어 둘 다. 실존 인물(특히 아이)이 나오는 클립은 확인받는다.
2. **구간 받기 + 세로로** — 클립마다 `clip.py fetch <콘티 id> r1 <주소> --best 3.5 --vertical`
   - `--best`: 유튜브 '가장 많이 다시 본 구간'에서 3.5초를 고른다(손으로 in · out 을 찍지 않는다)
   - `--vertical`: 주인공(동물 · 사람)을 찾아 카메라가 따라가는 9:16. 둘이 세로 화면에 안 들어가면 가운데 띠 + 뒤는 같은 영상을 흐리게(가로 원본 순위 쇼츠의 표준 배치). 가로판은 clip_h.mp4 로 남는다
3. **콘티** — 장면 = 클립 하나, 5위 → 1위(마지막이 가장 센 것). 첫 장면 3초 이하(L05). 역할 hook · item … · reveal, `visual.kind: "footage"`, `screen: "실사 영상"`, `reference: ["<X-ray 한 영상 id>"]`, id 는 `YYYY-MM-DD-이름-01`.
4. **화면 요소(refine, 장면 0 = 영상 전체 · COMP=Main)** — `typo-headline`(L1 강조색 · L2 "랭킹 TOP5", T1 = 영상 끝) · `typo-rank`(ITEMS 1위부터 · TIMES 각 클립 시작 초).
5. **반응 자막(장면마다 `typo-react` 두 번)** — 상황(0~1.6초) → 반응(그 뒤). 위치 Y≈1330(화면 69%, 클립 위 아래쪽), 크기 58. 말투는 레퍼런스대로: **동물 속마음 대사**("냥: 한 발짝만 더 와봐", "곰: ...난 갈게") · ㅋㅋㅋ · "?.." · ";;". 설명조("유리 사이에 두고 기싸움")는 밋밋하다. 레퍼런스 문장을 그대로 베끼지 않는다.
6. **소리** — 클립 원음은 엔진이 자동으로 넣는다(Clips 트랙 · 클립마다 크기 맞춤). **내장 효과음(pop · swoosh)과 내장 신스 작곡은 쓰지 않는다**(유치하고 유행과 무관 — 2026-11-08 사용자 평가).
   - 배경 곡: `python3 engine/research/trend_music.py "<주제어>" "<영어 주제어>" …` → 같은 분야 쇼츠가 쇼츠 편집기에서 실제로 붙인 곡(조회수 합 순) → 콘티 `music_library: {track, examples, start_hint, why}`. 영상 파일에는 넣지 않는다(유튜브가 라이선스를 가진 곡이라 수익 문제 없음).
7. **업로드 안내** — `python3 engine/publish/upload_guide.py data/storyboards/<id>.json` → `data/out/<id>.upload.md`(설명란 · 클립 출처 자동 · 쇼츠 편집기에서 붙일 곡 · 시작 지점). 업로드는 사용자가 요청할 때만.

## 원칙
- 클립은 짧게 · 우리 편집(순위 · 제목 · 반응 · 곡)을 얹는다 — 거의 그대로 옮긴 영상은 수익화(재사용 콘텐츠)에서 막힌다.
- 권리는 원작자에게 있다. 신고 위험은 채널 운영자 판단. 출처는 언제나 남긴다(설명란에 자동).
- 출처 표시는 저작권 허락이 아니다 — 최신 곡을 영상에 직접 넣으면 Content ID 로 수익이 권리자에게 간다. 곡은 쇼츠 편집기 라이브러리로.
- 검사기는 이 형식을 안다: 같은 종류 연속(R01 · T37) · 인물 없음(R03 · R07) · 재료 종류(V41) 경고는 나오지 않고, 컷 리듬(T34)은 레퍼런스 X-ray 기준이다.
