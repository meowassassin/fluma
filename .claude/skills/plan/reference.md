# 기획 참고 (plan 스킬에서 필요할 때만 읽는다)

## 기준점 — 사용자가 기준을 말하면 먼저 고정한다
- 그 기준의 **공식 영상 2~3편**을 찾아(trends `--channel` 로 공식 채널) `analyze_ref.py` 로 분석하고, 바로
  X-ray 프레임을 직접 보고 배경 · 빛 · 색 · 배치 · 재질 · 카메라 · 글자 · 속도 · 피할 것을 콘티 `constraints` 에 한 줄로 적는다. 기준 프레임과 문법 요약을 사용자에게 보여 주고 "이게 원하신 감성이 맞나"를 확인한다.
- 그 뒤 방향(배경색 · 글자 · 리듬 · 재료 고르기)은 기준 문법을 따르고, 초안은 레퍼런스와 나란히(sheet.png) 보고 기준과 다른 점을 고친 뒤 보여 준다.
- **콘셉트도 기준 안에서**: 안마다 "기준 문법 중 무엇을 그대로 쓰고, 우리 주제의 무엇으로 바꾸나"를 한 줄로. 기준과 다른 세계(따뜻한 카페 · 스톡 군중 · 흔한 매장 풍경)로 가는 안은 내지 않는다.
- **사용자가 "느낌이 아니다"라고 하면 기준을 바꾸지 말고 기준과 다른 점부터 본다** — 다른 브랜드 · 다른 문법으로 갈아타지 않는다(2026-11-09: 애플 → 샤넬 → 회색 무대 → 쇼릴 → 회전초밥으로 열 번 넘게 흘러가 결과가 무너짐).
  기준 자체를 바꾸는 건 사용자가 바꾸자고 할 때만.
